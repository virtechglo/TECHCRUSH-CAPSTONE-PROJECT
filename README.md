## 📌 PROJECT OVERVIEW

This project is an Ethical Hacking Capstone Project developed
to demonstrate practical cybersecurity knowledge and hands-on
experience with penetration testing and vulnerability assessment.

The project was carried out in a controlled virtual laboratory
environment using Kali Linux running on Oracle VirtualBox.

The primary goal was to understand how cybersecurity
professionals identify security weaknesses, assess potential
risks, and recommend appropriate security measures to improve
system and network security.

This project demonstrates practical exposure to ethical
hacking methodologies, security assessment, and cybersecurity
best practices.

The major objectives of this project include:
